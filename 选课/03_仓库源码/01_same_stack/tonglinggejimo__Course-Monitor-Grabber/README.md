# Course Monitor & Grabber (某大学抢课助手)

这是一个用于某大学选课系统的自动化抢课与监控工具。

本项目包含两个版本的脚本：

1.  **`course_monitor.py` (推荐)**：全自动版本。支持自动登录、验证码识别、交互式选课、智能调度监控（适用于制度修改后——使用抽签的方式，智能调度+监控课程余量）。
2.  **`get_the_fxxk_class.py`**：手动配置版本。需要手动提取 Cookie 和 Token，适合开发者或特殊调试使用。（适用于制度修改前——手动点击抢课的方式）

## 功能特性 (course_monitor.py)

- **自动登录**：集成 `ddddocr` 自动识别验证码，支持 DES 密码加密，具备无限重试机制确保登录成功。
- **交互式选课**：自动拉取并在终端展示当前可用课程列表，通过输入序号即可快速锁定目标课程。
- **智能调度 (Smart Schedule)**：
  - **定频模式**：按用户设定的分钟间隔循环监控。
  - **智能模式**：自动计算並在关键时间点（`:00`, `:05`, `:25`, `:30`, `:35`, `:55`）触发抢课，精准覆盖退课高发期。
- **自动退出**：抢课成功后自动停止，避免重复请求。

## 环境要求

需要同时安装 Python 和 Node.js。

1.  **Python 3.8+**
    - 依赖库：`requests`, `ddddocr`
2.  **Node.js**
    - 用于运行 `login_encrypt.js` 进行密码加密。

### 安装依赖

```bash
pip3 install requests ddddocr
# 确保 node 命令可用
node -v
```

## 使用指南

### 方式一：全自动监控 (course_monitor.py)

这是主要使用的脚本。

1.  **运行脚本**：

    ```bash
    # 建议使用 -u 参数禁用缓存，并通过 tee 命令保存日志
    python3 -u course_monitor.py "你的密码" 2>&1 | tee monitor.log
    ```

    _(注：如果不通过命令行参数传递密码，脚本启动后会提示输入)_

2.  **操作流程**：
    - 脚本会自动尝试登录。
    - 登录成功后，显示课程列表。
    - 输入课程对应的 **IDX** (序号) 选择要抢的课。
    - 输入监控间隔：
      - `> 0` (例如 `1`)：每隔 1 分钟尝试一次。
      - `-1`：进入 **智能调度模式** (推荐)，在整点和半点前后的关键时间点自动抢课。
      - `0`：退出程序。

### 方式二：手动高频抢课 (get_the_fxxk_class.py)

如果您需要极高频率的并发请求，或者自动登录无法工作，可以使用此脚本。

1.  使用浏览器登录选课系统，按 F12 打开开发者工具。
2.  获取 `Cookie` 和 `Token`。
3.  编辑 `get_the_fxxk_class.py`，手动填入：
    - `cookie_str`
    - `token`
    - `teaching_class_ids` (目标课程 ID)
    - `elective_batch_code` (选课批次)
4.  运行脚本：
    ```bash
    python3 get_the_fxxk_class.py
    ```

## 文件说明

- `course_monitor.py`: 主程序，集成了登录、查询、选课和调度逻辑。
- `login_encrypt.js`: 辅助脚本，用于实现选课系统的 DES 密码加密算法。
- `get_the_fxxk_class`: 纯 HTTP 请求版本的抢课脚本，需手动抓包配置。
