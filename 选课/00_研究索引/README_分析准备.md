# NNU 选课系统分析资料库

本目录用于对本地保存的南京师范大学学生选课页面快照、公开资料和公开仓库源码进行合规的静态分析与版本对比。

## 当前状态

- 本地证据：3 份页面快照及其完整静态资源，已复制到 `01_本地证据/raw/`。
- 工作区根目录原有的 `选课*.html` 与 `选课*_files/` 保持不动，作为用户原始材料；后续分析使用已登记的 `raw/` 或 `sanitized/` 副本。
- 脱敏证据：对应副本位于 `01_本地证据/sanitized/`；页面 URL 中的会话 `token` 已替换为 `[REDACTED_TOKEN]`。
- 公开资料：官方说明、公开 Gist、GreasyFork 脚本和来源链接放在 `02_公开资料/`。
- 检索依据：`用户提供的技术栈检索记录.txt` 保留了本次整理使用的原始检索记录。
- 仓库源码：仅收集公开仓库，不安装依赖、不执行代码、不向真实选课系统发起请求；目标目录为 `03_仓库源码/`。
- 静态提取：接口、前端模块、字段和快照差异放在 `04_提取分析/`。

## 目录约定

| 目录 | 用途 |
|---|---|
| `00_研究索引` | 研究范围、采集登记、仓库清单和入口文档 |
| `01_本地证据/raw` | 不改动的原始页面与资源副本，含可能敏感的会话信息 |
| `01_本地证据/sanitized` | 可用于共享和静态分析的脱敏页面副本 |
| `01_本地证据/metadata` | 文件哈希、来源 URL、时间、快照说明 |
| `02_公开资料` | 官方文档、公开脚本/Gist、外部来源记录 |
| `03_仓库源码` | 公开仓库的浅克隆源码，按关联度分组 |
| `04_提取分析` | 端点清单、字段模型、模块映射、版本比较 |
| `05_工具` | 只读/离线采集与提取脚本；默认不调用真实系统 |
| `06_报告` | 后续分析报告、图表和结论 |
| `99_quarantine` | 无法确认来源、疑似含凭据或需要人工复核的材料 |

## 分析边界

1. 仅分析本地快照和公开发布的资料/源码。
2. 不保存密码、验证码答案、Cookie、有效 token 或个人登录态到公开资料和源码目录。
3. 不运行第三方仓库代码，不执行安装脚本，不提交真实选课、退选、排队或批量查询请求。
4. 如需要对真实系统做任何主动测试，必须另行确认授权范围、测试窗口、速率限制和回滚方案；本资料库默认不包含主动测试工具。

## 推荐分析顺序

1. 先看 `01_本地证据/metadata/` 和 `04_提取分析/endpoint_inventory.csv`。
2. 再对照 `03_仓库源码/00_nnu_direct/`，确认南师大特有的认证与入口关系。
3. 用 `03_仓库源码/01_same_stack/` 对比同一 `xsxkapp` 产品族的页面、字段和调用顺序。
4. 最后查看 `03_仓库源码/02_adjacent/`，区分同栈实现、旧版本和误匹配。
