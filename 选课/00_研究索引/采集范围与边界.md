# 采集范围与边界

## 目标

建立一份可复核的静态研究资料库，用于回答：

- 本地页面属于哪个产品/版本族？
- 页面脚本公开暴露了哪些模块、接口路径和数据字段？
- 哪些公开仓库与本地页面在入口、路径、字段或调用顺序上相似？
- 哪些资料是当前版本证据，哪些只是历史参考？

## 纳入范围

- 用户本地提供的 HTML、JavaScript、CSS、图片和页面快照。
- 用户提供链接指向的公开 GitHub 仓库、公开 Gist、GreasyFork 脚本和学校公开操作说明。
- 只读的文件哈希、文本提取、代码搜索和版本登记。

## 排除范围

- 私有仓库、需要登录才能下载的内容和来源不明的网盘附件。
- 密码、验证码、Cookie、有效会话 token、个人学号/姓名等身份凭据。
- 对学校系统进行登录、抓包重放、批量轮询、抢课、退选、排队或压力测试。
- 运行第三方源码、安装其依赖、构建可直接操作真实系统的客户端。

## 证据等级

| 等级 | 含义 |
|---|---|
| A | 本地页面/资源原件或官方公开文件，可直接复核 |
| B | 公开仓库源码中明确出现的路径、域名或字段 |
| C | README、搜索摘要或二手描述，需要回到源码/原页复核 |
| D | 仅名称或推测，不作为技术结论依据 |

## 敏感信息处理

`01_本地证据/raw/` 是证据保全副本，可能包含页面 URL 中的会话 token 和课程数据，不应上传到公开仓库或发送给他人。对外分析优先使用 `01_本地证据/sanitized/`；任何新增 HAR、网络日志或截图都先放入 `99_quarantine/`，完成脱敏后再归档。
