# 后续采集清单（只读、脱敏、低风险）

## 优先补齐的资料

- [ ] NNU 官方选课通知/操作说明：学期、批次、预选/正选、选课策略和结果解释。
- [ ] 同一用户会话下的页面快照时间线：登录入口、主页、选课页、已选页、退选日志、失败弹窗；每份先脱敏再入库。
- [ ] 浏览器开发者工具导出的 HAR（只在获授权的个人测试会话内）：删除 Cookie、Authorization、token、密码、验证码、学号、姓名和课程个人记录后再归档。
- [ ] 每个请求的路径、方法、参数字段名、响应外壳、状态码和前端调用者；不保存真实参数值。
- [ ] `sessionStorage` 键名与字段结构的脱敏记录：`studentInfo`、`currentBatch`、`sysParam`、`currentCampus`、`bookParam`、`teachingClassType`。
- [ ] 公开仓库的 commit、许可证、README、依赖声明和核心接口命中位置。

## 记录模板

| 字段 | 记录内容 |
|---|---|
| 证据 ID | 日期/来源/状态，例如 `nnu-local-20260826-grablessons-clicked` |
| 来源 | 本地快照、官方公开文件、GitHub、Gist 或 GreasyFork |
| 时间 | 本地文件时间或公开页面访问时间，注明时区 |
| 版本线索 | `resUrl`、commit、脚本版本、文档发布日期 |
| 业务状态 | 入口/查询/已选/退选日志/失败提示等 |
| 脱敏状态 | `raw`、`sanitized`、`needs_review` |
| 哈希 | SHA-256 |
| 备注 | 仅写可复核事实和不确定性 |

## 明确不做

- 不自动登录、不猜测或识别验证码、不轮询真实系统、不提交选课/退选、不并发请求、不验证越权。
- 不把公开“抢课脚本”的运行方式直接迁移到 NNU；公开代码仅用于静态版本和字段对比。
